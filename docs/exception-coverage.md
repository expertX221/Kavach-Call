# Exception coverage

"Implemented" describes this prototype, not proof of production effectiveness.

| Situation                                  | Shipped behavior                                                                                                | Remaining work                                                                 |
| ------------------------------------------ | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------ |
| Family member jokes or uses trigger words  | Guided independent check plus explicit one-session dismissal; new speech is rechecked                           | Field testing and secure challenge rotation                                    |
| Genuine bank/police or delivery call       | Multiple signal categories; weak vocabulary alone cannot cause a high alert; delivery-code example              | Context classifier and representative evaluation                               |
| News, stories, training                    | Simple advisory and reported-speech suppression; practice scripts remain labeled                                | Robust conversation intent and negation                                        |
| New scripts or trigger avoidance           | Behavioral text patterns for urgency, secrecy, money and isolation                                              | Learned classifier, reviewed rule updates; no claim to detect every script     |
| Hinglish/Tamil/accents                     | Illustrative English, Hindi/Hinglish and Tamil patterns; recognition language selector                          | Language/accent benchmarks; complete vocabulary and better local transcription |
| Poor transcription/noise/multiple speakers | User/browser quality input produces analysis-limited output                                                     | Noise suppression, acoustic quality and diarization models                     |
| Phone-quality deepfakes or legitimate IVR  | Voice authenticity explicitly not analyzed; IVR vocabulary alone is not flagged                                 | Telephony-trained anti-spoofing model and calibration                          |
| Android caller-audio restrictions          | Consent-based mic/speakerphone path and typed transcripts; no call interception claim                           | Native platform feasibility and policy review                                  |
| Battery and latency                        | No continuous background capture; local small rules; user starts/stops mic                                      | Device battery profiling and native inference                                  |
| No internet                                | Production shell cache, local text rules and practice after first online load                                   | Offline speech packs/models and cross-browser testing                          |
| Alert fatigue                              | Strong alert requires several categories; per-signal deduplication and per-episode alert key                    | Real false-positive measurement and feedback tuning                            |
| Told to disable warnings or keep secrets   | Isolation and secrecy are separate explained signals                                                            | Adversarial speech evaluation                                                  |
| Elderly users / hearing impairment         | Large-text mode, optional device speech, visible captions and alerts                                            | User testing, full language localization and screen-reader audit               |
| Victim under intense pressure              | Strong warning and user-selected verification; official help links                                              | Opt-in verified contact notification service; app cannot hang up calls         |
| Leaked safe-word or absent family app      | Question-based checks; editable by replacing local contact; copyable check-in draft and saved-number call links | Encrypted sync and recipient verification                                      |
| Caller-ID spoofing                         | No trust based on incoming number; independent callback guidance                                                | Private moderated reputation service                                           |
| Poisoned reports / innocent number         | No public number reporting or reputation accusations                                                            | Authentication, rate limits, corroboration, moderation and appeals             |
| Consent and data protection                | Mic consent, no app audio recording, transient transcripts, optional local summaries                            | Jurisdiction-specific legal/privacy review before launch                       |
| Personal identifiers                       | Numeric/email/UPI redaction and explicit manual review before excerpt export                                    | Comprehensive PII detection; redaction is not guaranteed                       |
| Practice mode                              | Simulated scripts and clearly marked drafts; no outbound service exists                                         | Preserve a server-side no-send gate when services are added                    |
| Call moves to WhatsApp/video               | Explained switch-app, remote-access and screen-sharing signals                                                  | Native awareness of app switching; no video surveillance                       |
